# Awesome Agentic Keyboards

A curated list of agentic keyboards, AI keyboards, and mobile AI agents that are moving the keyboard from text input toward action execution.

## What is an agentic keyboard?

An agentic keyboard is a mobile keyboard that can understand intent and take action directly from the keyboard interface.

Examples of actions include:

- Searching the web
- Booking reservations
- Sharing links or locations
- Drafting contextual replies
- Triggering cross-app workflows

More background: https://www.agentickeyboardguide.com/what-is-agentic-keyboard?utm_source=github&utm_medium=referral&utm_campaign=awesome_repo
